# 列模板（创建项目预置列）

## 入口
桌面端：左上角头像 →「系统设置」→「项目设置」→「项目模板」。
对应后端：`POST api/system/column/template`，`type=get` 读取，`type=save` 写入（限 admin）。

## 是什么
创建新项目时，用户可以选用项目模板。旧模板只保存列名；从现有项目复制的模板还保存列表颜色、列表关联状态，以及工作流状态、流转范围、流转模式、负责人限制和状态关联列表。

管理员可以标记一个「默认模板」。打开新建项目窗口时会自动选中它，也可改选其他模板或空白模板。默认模板只影响之后创建的项目。

例如内置一个「研发任务」模板：
- 列：待办、进行中、待测试、已完成

新建项目时选择这个模板，项目就自动有这 4 列。

## 字段结构
旧模板保存时上传 `list` 数组：

```json
[
  {
    "name": "研发任务",
    "columns": "待办,进行中,待测试,已完成"
  },
  {
    "name": "市场活动",
    "columns": "策划,执行中,复盘"
  }
]
```

- **name** — 模板名（必填）
- **columns** — 逗号分隔的列名字符串，服务端会按 `,` 切分 → 去重 → 去空，落库为数组
- **default** — 是否作为新项目默认模板；最多一个模板可设为默认
- **config** — 从项目复制时生成的列表与工作流快照。系统在新项目中重新生成列表和状态 ID，双向关联会指向新项目的对象

任何缺 `name` 或 `columns` 的条目会被服务端跳过；最终为空数组直接报「参数为空」。

## 操作步骤
1. 进入「项目设置」tab 的「项目模板」区块
2. 「新增模板」→ 填写模板名
3. 在列输入框输入列名（多个用逗号分隔）
4. 如需完整配置，点击「从项目复制」，选择已设置好工作流和列表的来源项目并导入
5. 可勾选一个「默认模板」
6. 点击页面底部「提交」，与同页项目设置一起保存并立即生效

删除某一行时点击最右侧的删除图标并确认；删除先保留在当前表单中，点击「提交」后才会生效，点击「重置」可撤销未提交的删除。系统至少保留一个项目模板。

## 与项目创建的关系
用户「新建项目」对话框的模板下拉就是这里维护的列表。选中模板后，新项目会按模板生成空列表与工作流。若模板中的状态原本指定了负责人，新项目改由创建人担任，避免引用未加入新项目的成员。用户仍可在创建时关闭工作流。

## 不支持
- 不能复制来源项目的任务卡、成员或自定义字段
- 不能跨终端导出/导入模板
- 修改模板不会回溯到已创建的项目（仅对新项目生效）
