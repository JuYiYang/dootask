# AI 自动跟进

入口：系统设置 → AI 自动跟进。模型服务地址、API Key、模型名、语气、项目范围均可配置。地址填写 API 基础地址，不包含 `/chat/completions`。API Key 不返回浏览器，编辑时留空保留。可以先保存未填写模型的关闭配置，填写模型后再开启。

## 每周总结
选择接收账号、星期和时间。按服务器时区，在指定时间起一小时内运行，每账号每周最多一次，由任务提醒机器人私信。汇总最近七天完成任务和当前未完成任务，仅包含所选项目内该账号负责或协助的任务，且账号仍为项目成员。按项目归纳本周成果、当前进展与风险、下周建议，合并同类事项，不逐条列出全部任务；本周完成与当前未完成存量分别统计，存量不代表本周工作量。待测试与验收失败等保留真实状态，不推断上线、验收结果或阻塞原因。全文最多引用8项代表性任务，任务名称可点击。完整汇总数字不受明细限制，每次最多提供200项明细，超出会注明主题归纳可能不完整。建议不代表确定的计划或已知阻塞。任务链接沿用任务邮件汇报的公开站点地址。

## 任务会话催办
设置时间、工作日开关、到期前小时数、未更新天数、间隔（最少24小时）。扫描所选项目的未完成主任务，对逾期、即将到期或长期未更新的任务在任务讨论中 @负责人。人工消息和任务更新时间都算更新；机器人消息不算人工更新。已完成、取消、归档或删除任务及归档项目不催办，无有效负责人不发送。每个任务每天最多一次，指定时间起一小时内运行。管理员可关闭任一开关停止该类后续处理。

默认语气自然直白，略带俏皮，不撒娇、不用表情、不虚构事实。模型调用失败后15分钟再试；若发送过程被中断，记录保留发送中，不自动重发，需要管理员查看原会话核对。

## 测试与记录
先保存，再选择周报账号或任务ID测试，只生成并展示结果，不发送消息。预览按Markdown排版，标题和任务链接正常显示，模型生成的HTML与图片不会执行；预览和定时私信共用同一份内容规则。周报账号默认选择当前账号（须在接收范围内），否则选择范围内第一个账号；无有效账号时不可生成。项目、账号和星期下拉菜单在页面上层展开，不受滚动表单裁剪。预览最多等待60秒，超过模型调用的45秒限制；网络异常会显示明确提示，失败原因会保留在测试区域，重新生成时清空上次结果和错误。最近记录显示种类、账号或任务ID、周期、发送状态和时间。功能无需安装 AI 插件，但不会开启其聊天、任务分析等能力。

接口：`api/aiautomation/settings`、`save`、`options`、`preview`、`history`，均需系统管理员；save 和 preview 使用 POST JSON，其余使用 GET。此功能不读取业务知识库、不修改任务状态。
